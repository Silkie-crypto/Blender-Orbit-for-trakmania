FEATURES
- Customizable keybindings — Click to rebind controls (some bindings are not fully functional yet).
- WAZD camera movement — Move the camera forward, backward, left, and right.
- Adjustable orbit and pan bindings — Assign right or middle mouse buttons.
- Sensitivity adjustments — Customize orbiting, panning, zooming, and keyboard movement.
- Smooth camera movement — Smoother rotation, panning, and focus transitions.
- Smooth focus (F) — Focus the camera on the editor cursor.
- Page Up / Page Down — Raise or lower copied sections.
- Ctrl+Z — Use Trackmania's native Undo function.


KNOWN ISSUES AND lIMITATIONS

This mod is nowhere near perfect!

Some keybindings are harder to change than others. For example, Trackmania already uses S as its Save shortcut. I haven't found a reliable way to override this, which is why backward camera movement currently uses Z OR X instead.

There are also some unfinished features and occasional issues that I plan to improve in future versions.

Blender Orbit currently requires Openplanet Developer Mode.



INSTALLATION

1. Download and install Openplanet.
2. Install the Editor++ (E++) plugin through Openplanet.
3. Download the Blender Orbit release from this repository.
4. Place the Blender Orbit plugin package in your Openplanet plugins folder.
5. Enable Developer Mode in Openplanet.
6. Launch the Trackmania map editor and enable Blender Orbit.


IMPORTANT: You can create and save maps while using Developer Mode. Switch back to Official Mode when you want to play normally and set official records.

Blender Orbit does not currently work outside Developer Mode.
